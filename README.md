# Tarkov Map — интерактивная карта

Карта открыта для всех без входа. Вход для администратора скрыт: **двойное нажатие на иконку ⚙** в правом верхнем углу.

## Ссылки на метки
Формат: `index.html#map=woods&level=0&marker=ID` — открывается на любом устройстве, карта и этаж берутся из ссылки.
Старые ссылки `#marker=ID` тоже работают (карта ищется автоматически).

## Firebase Rules (ОБЯЗАТЕЛЬНО)
Чтение карты без входа и запись только админам. Пример — проверьте в Rules Playground и адаптируйте под свои поля:

```json
{
  "rules": {
    "maps": {
      ".read": true,
      "$map": {
        "markers": {
          ".write": "root.child('users').child(auth.uid).child('role').val() === 'admin'"
        }
      }
    },
    "users": {
      ".read":  "root.child('users').child(auth.uid).child('role').val() === 'admin'",
      ".write": "root.child('users').child(auth.uid).child('role').val() === 'admin'",
      "$uid": {
        ".read": "auth.uid === $uid",
        ".write": "auth.uid === $uid && !data.exists() && newData.child('role').val() === 'user' && newData.child('banned').val() === false",
        "nickname": { ".write": "auth.uid === $uid" },
        "photoURL": { ".write": "auth.uid === $uid" }
      }
    }
  }
}
```
Если пользователь сам сбрасывает `accessLevel` по истечении срока (auth.js), добавьте для этого поля отдельное правило.

Также ограничьте API-ключ Firebase по домену сайта в Google Cloud Console → Credentials.

## Приложение и офлайн-режим
- Сайт можно установить на телефон: меню браузера → «Добавить на главный экран» / «Установить приложение» (или кнопка «📲 Установить приложение» в меню карты).
- Офлайн (только просмотр): один раз откройте карту с интернетом, затем нажмите в меню **«📥 Сохранить для офлайна»**: скачаются все карты и метки. Дальше всё открывается без сети.
- Без интернета редактирование и добавление меток отключены.
- Картинки меток с чужих сайтов офлайн не сохраняются, если сервер не разрешает это (CORS). Чтобы фото работали офлайн, храните их в папке `files/` репозитория.
- После крупных изменений структуры кеша увеличьте `VERSION` в `sw.js`.

## Торговцы
Список торговцев — в `constants.js` (объект `TRADERS`). Чтобы добавить нового, допишите строку: ключ латиницей (потом не менять) и русское имя.

## Видео в метках
В редакторе метки есть блок **«Видео»**: вставьте ссылку YouTube (обычную, youtu.be или Shorts), Twitch (запись эфира или клип), Vimeo или прямой `.mp4`/`.webm`, можно добавить подпись и несколько видео. В окне метки появляется плеер с кнопкой «⛶ На весь экран». YouTube загружается только после нажатия на превью. Видео работает только при наличии интернета.

## Ссылки на картинки (для офлайна)
Лучший вариант — положить картинку в папку `files/` этого репозитория и указать `files/имя.jpg` (лучше латиницей). Ссылки GitHub вида `github.com/…/blob/…?raw=true` сайт сам превращает в `raw.githubusercontent.com/…`, и такие картинки тоже сохраняются для офлайна. Картинки с других сайтов могут не сохраняться, если сервер не разрешает это (CORS).

## Дома (планировки внутри зданий)
1. Нарисуйте план каждого этажа отдельной картинкой (лучше SVG) и загрузите в репозиторий, например `images/houses/dom-lesopilka/floor1.svg`.
2. Поставьте на карте любую метку и включите в её форме галочку **«🏠 Вход в дом»** (это отдельная функция метки, а не её тип; тип у метки остаётся обычный). Появится блок «Дом»: добавляйте этажи кнопкой «+ Добавить этаж» (первая строка — самый нижний этаж), в каждой укажите название («Подвал», «1 этаж», «Чердак»…) и путь к картинке. Этажей может быть сколько угодно; кнопки ▲▼ меняют порядок, галочка «открывать первым» задаёт стартовый этаж.
3. Игрок нажимает значок дома — открывается план на весь экран, кнопки ▲▼ переключают этажи, кнопка «← К карте» возвращает на карту. Метки внутри дома добавляются как обычные (на выбранном этаже).
4. Админ при нажатии на значок видит окно метки с кнопкой «Войти в дом».

**Правила Firebase.** Добавьте в `rules` рядом с `maps`:
```json
"houses": {
  ".read": true,
  ".write": "root.child('users').child(auth.uid).child('role').val() === 'admin'"
}
```

## Типы меток и подсказка при наведении
- У метки есть основной тип и необязательные **дополнительные типы** (галочки-чипы под выбором типа). В фильтре метка находится по любому из своих типов.
- **Подсказка при наведении (ПК)** всегда одного размера на экране и не зависит от масштаба карты. В форме метки можно отдельно выключить картинку или текст и задать размер картинки и текста в % (пусто — 100%). В окне метки картинка показывается всегда, если она указана.

## Настройка зума (админ)
Справа снизу над кнопками зума админу виден значок «⚙ Зум»: ползунки чувствительности для кнопок «+ / −» и для щипка двумя пальцами (изменения сразу работают на карте). Щипок экспоненциальный: при чувствительности 1.0 карта увеличивается во столько же раз, во сколько раздвинули пальцы (как в обычных картах); 1.5 — заметно быстрее. Кнопка «Сохранить для всех» записывает значения в Firebase (`settings/zoom`), и они действуют у всех игроков.
В правила Firebase нужно добавить блок:
```json
"settings": {
  ".read": true,
  ".write": "root.child('users').child(auth.uid).child('role').val() === 'admin'"
}
```
