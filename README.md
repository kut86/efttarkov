# Tarkov Map — интерактивная карта

Карта открыта для всех без входа. Вход для администратора скрыт: **двойное нажатие на иконку ⚙** в правом верхнем углу.

## Ссылки на метки
Формат: `index.html#map=woods&level=0&marker=ID` — открывается на любом устройстве, карта и этаж берутся из ссылки.
Старые ссылки `#marker=ID` тоже работают (карта ищется автоматически).

## Firebase Rules (ОБЯЗАТЕЛЬНО)
Чтение карты без входа и запись только админам. Пример — проверьте в Rules Playground и адаптируйте под свои поля:

```json
{
  "rules": {
    "maps": {
      ".read": true,
      "$map": {
        "markers": {
          ".write": "root.child('users').child(auth.uid).child('role').val() === 'admin'"
        }
      }
    },
    "users": {
      ".read":  "root.child('users').child(auth.uid).child('role').val() === 'admin'",
      ".write": "root.child('users').child(auth.uid).child('role').val() === 'admin'",
      "$uid": {
        ".read": "auth.uid === $uid",
        ".write": "auth.uid === $uid && !data.exists() && newData.child('role').val() === 'user' && newData.child('banned').val() === false",
        "nickname": { ".write": "auth.uid === $uid" },
        "photoURL": { ".write": "auth.uid === $uid" }
      }
    }
  }
}
```
Если пользователь сам сбрасывает `accessLevel` по истечении срока (auth.js), добавьте для этого поля отдельное правило.

Также ограничьте API-ключ Firebase по домену сайта в Google Cloud Console → Credentials.

## Приложение и офлайн-режим
- Сайт можно установить на телефон: меню браузера → «Добавить на главный экран» / «Установить приложение» (или кнопка «📲 Установить приложение» в меню карты).
- Офлайн (только просмотр): один раз откройте карту с интернетом, затем нажмите в меню **«📥 Сохранить для офлайна»**: скачаются все карты и метки. Дальше всё открывается без сети.
- Без интернета редактирование и добавление меток отключены.
- Картинки меток с чужих сайтов офлайн не сохраняются, если сервер не разрешает это (CORS). Чтобы фото работали офлайн, храните их в папке `files/` репозитория.
- После крупных изменений структуры кеша увеличьте `VERSION` в `sw.js`.

## Торговцы
Список торговцев — в `constants.js` (объект `TRADERS`). Чтобы добавить нового, допишите строку: ключ латиницей (потом не менять) и русское имя.
